# MISIS Schedule

Скрипт предназначен для преобразования расписания НИТУ «МИСИС» из Excel в файл календаря iCalendar (`.ics`).
Все параметры задаются в файле `.env`, который нужно создать на основе шаблона `.env.template`.

## Структура Excel-файла

Файл расписания (`.xls` или `.xlsx`) должен иметь следующую структуру:

- **Первые три столбца**:
  - `Дата` – название дня недели указывается только в первой строке дня.
  - `Номер` – номер пары от 1 до 7.
  - `Время` – интервал начала и конца пары в формате `HH:MM:SS - HH:MM:SS`.
- **Столбцы групп** располагаются блоками по четыре для каждой академической группы:
  1. Занятие подгруппы 1.
  2. Аудитория подгруппы 1.
  3. Занятие подгруппы 2.
  4. Аудитория подгруппы 2.
- Первая строка таблицы содержит номера подгрупп ("1" и "2"). Далее каждая пара занимает две строки: основная с данными и пустая строка-разделитель.

Пример структуры можно найти в файле `template.xls` в корне проекта.

## Конфигурация

1. Скопируйте файл `.env.template` в `.env` и заполните значения.
2. Основные параметры:
   - `GROUP_NAME` – название группы в таблице.
   - `SUBGROUP_NUMBER` – номер подгруппы (1 или 2).
   - `SHEET_NAME` – название листа.
   - `SCHEDULE_SOURCE` – режим получения файла расписания: `file`, `url` или `auto`.
     - `file` – используется путь `SCHEDULE_FILE_PATH`.
     - `url` – скачивание из `SCHEDULE_FILE_URL`.
     - `auto` – автоматический поиск ссылки на странице `SCHEDULE_PAGE_URL` по CSS‑селектору `SCHEDULE_LINK_SELECTOR`.
   - `UPPER_WEEK_START` и `LOWER_WEEK_START` – даты (понедельник) начала первой верхней и нижней недель.
   - `ICS_FILENAME` – имя создаваемого календарного файла.

## Использование

Установите зависимости и запустите генератор:

```bash
pip install -r requirements.txt
python generate_schedule.py
```

Скрипт сравнивает созданный `.ics` с существующим файлом и сообщает, были ли изменения.

## Настройка аудиторий

В функции `create_event` есть блок с `pass`, где можно реализовать собственную логику замены аудитории
(например, для "Каф. ИЯКТ" в разные дни или недели). Используйте `start.weekday()` и другие параметры,
чтобы подставлять нужные значения.
