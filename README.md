# MISIS Schedule

Проект предназначен для преобразования расписания НИТУ "МИСИС", представленного в формате Excel, в файл календаря iCalendar (`.ics`). Скрипт `update_schedule.py` выбирает данные по указанной группе и формирует события на верхнюю и нижнюю недели.

## Структура Excel-файла расписания

Файл расписания (`.xls` или `.xlsx`) должен иметь следующую организацию:

- **Первые три столбца**:
  - `Дата` – название дня недели указывается только в первой строке дня.
  - `Номер` – номер пары от 1 до 7.
  - `Время` – интервал начала и конца пары в формате `HH:MM:SS - HH:MM:SS`.
- **Столбцы групп** располагаются блоками по четыре для каждой академической группы:
  1. Занятие подгруппы 1.
  2. Аудитория подгруппы 1.
  3. Занятие подгруппы 2.
  4. Аудитория подгруппы 2.
- Первая строка таблицы содержит номера подгрупп ("1" и "2") в соответствующих столбцах. Далее каждая пара занимает две строки: основная строка с данными и пустая строка-разделитель.

Пример структуры взят из файла `template.xls` в корне проекта.

## Подготовка окружения

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Подготовьте текстовые файлы с параметрами:
   - `group_name.key` – название группы так, как оно указано в таблице (например, `ББИ-24-1`).
   - `sheet_name.key` – название листа в Excel-файле.
   - `schedule_file_url.key` – путь или URL к файлу расписания.

## Использование

1. При необходимости задайте `use_auto_file_url = True` в `update_schedule.py`, чтобы автоматически получать ссылку на актуальный файл расписания с сайта МИСИС.
2. Запустите скрипт:
   ```bash
   python update_schedule.py
   ```
3. В результате будет создан файл `schedule4.ics` в каталоге проекта. Если такой файл уже существует, скрипт сравнит содержимое и сообщит, были ли изменения.

## Примечания

- Скрипт поддерживает только структуру Excel-файла, описанную выше. При отличиях формат необходимо адаптировать.
- Файл `template.xls` служит примером и может использоваться для проверки структуры.
