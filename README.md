# MISIS Schedule

## Что это

MISIS Schedule преобразует Excel-расписание НИТУ «МИСИС» в календарь iCalendar (`.ics`).
Приложение работает в браузере: файл загружается вручную, пользователь выбирает группу и
подгруппу, проверяет занятия и скачивает готовый календарь.

## Возможности

- принимает актуальные файлы `.xls` и `.xlsx`;
- получает листы, группы и подгруппы из самого Excel-файла;
- поддерживает группы с одной, двумя или тремя подгруппами;
- показывает только реальные занятия и позволяет исправить предмет или аудиторию;
- берёт дни, номера пар и время непосредственно из Excel;
- создаёт повторяющиеся раз в две недели события в часовом поясе `Europe/Moscow`;
- ограничивает повторение датой окончания семестра;
- сравнивает новый календарь с ранее сохранённым `.ics` по стабильным UID и показывает
  добавленные, удалённые и изменённые занятия (без ложных изменений из-за `DTSTAMP`);
- не использует Selenium, `.env`, базу данных и внешние сервисы.

## Онлайн-версия

Приложение доступно по адресу: [misis-schedule.streamlit.app](https://misis-schedule.streamlit.app/).

## Как использовать

1. Скачайте актуальное Excel-расписание МИСИС.
2. Откройте веб-приложение.
3. Загрузите `.xls` или `.xlsx`.
4. Выберите курс (лист), группу и существующую подгруппу.
5. Укажите понедельники начала верхней и нижней недель, а также дату окончания семестра.
6. Проверьте предварительный просмотр и при необходимости исправьте предмет или аудиторию.
7. Нажмите «Сформировать календарь» и скачайте `.ics`.
8. При необходимости загрузите ранее сохранённый `.ics` в секции сравнения: если изменений
   нет, повторный импорт не нужен; иначе приложение покажет их список.
9. Импортируйте файл в привычное календарное приложение.

Данные загруженного расписания не сохраняются между сессиями.

## Поддерживаемый формат Excel

Приложение рассчитано на актуальный формат расписаний МИСИС:

```text
Дата | Номер | Время | блоки академических групп
```

- первая строка заголовка содержит названия групп;
- вторая строка при наличии содержит номера подгрупп;
- каждая подгруппа занимает две колонки: «предмет + аудитория»;
- число подгрупп у разных групп может отличаться;
- две последовательные строки одной пары описывают верхнюю и нижнюю недели;
- название дня может быть указано только в первой строке дня;
- время пары берётся из столбца `Время`.

Парсер сначала определяет границы блока выбранной группы и только затем ищет в нём
подгруппы. Поэтому данные соседней группы не могут случайно попасть в календарь.

## Локальный запуск

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

В Windows активируйте окружение командой:

```powershell
.venv\Scripts\Activate.ps1
```

### Дополнительный CLI

Основной интерфейс — Streamlit. Для локальной автоматизации доступен тонкий CLI-адаптер:

```bash
python generate_schedule.py schedule.xls \
  --sheet "3 курс" --group "ББИ-24-БА-1" --subgroup 1 \
  --upper-week-start 2026-09-07 --lower-week-start 2026-09-14 \
  --semester-end 2026-12-31 --output schedule.ics
```

Он также не использует `.env`, Selenium или сетевую загрузку.

## Структура проекта

```text
misis_schedule/
  parser.py      # Excel → нормализованные Lesson
  models.py      # Lesson и WeekType
  rules.py       # правила аудиторий корпусов Б и Г
  calendar.py    # Lesson + даты семестра → iCalendar
  compare.py     # семантическое сравнение двух iCalendar по UID
streamlit_app.py # веб-интерфейс
generate_schedule.py # необязательный CLI-адаптер
tests/           # тесты и искусственный Excel fixture
```

## Ограничения

Приложение не является универсальным импортёром произвольных Excel-файлов. Оно поддерживает
фактическую структуру расписания МИСИС с двумя строками заголовков и парными строками
верхней/нижней недели. При повреждённой или другой структуре приложение покажет понятную
ошибку вместо создания неполного календаря.

## Разработка

Полный актуальный файл расписания используется только для локальной ручной проверки и не
добавляется в Git. В тестах лежит небольшой искусственный `.xlsx` fixture, который повторяет
ключевые особенности layout: несколько групп, 1–3 подгруппы, верхнюю и нижнюю недели,
пустую аудиторию и пустой слот.
